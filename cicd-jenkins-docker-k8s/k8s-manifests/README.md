📌 Overview

This project demonstrates a complete CI/CD pipeline that automates building, testing, containerizing, and deploying an application using modern DevOps tools. The pipeline ensures faster software delivery, consistency, and zero-downtime deployments through Kubernetes.

🚀 Tech Stack Used

Jenkins – Continuous Integration & Orchestration

Git & GitHub – Source Code Management

Docker – Containerization

Docker Hub / ECR – Container Registry

Kubernetes (K8s) – Deployment & Orchestration

Terraform / Ansible (optional) – Infrastructure provisioning & config management

Prometheus & Grafana (optional) – Monitoring

🎯Objectives

Automate the entire application delivery process.

Build application using Jenkins.

Run automated tests.

Dockerize the application.

Push Docker images to the registry.

Deploy the application on Kubernetes.

Implement rolling updates & rollback functionality.

Ensure repeatable and reliable delivery workflows.
