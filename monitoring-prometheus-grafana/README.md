
1. Prometheus

Open-source monitoring and alerting toolkit

Pull-based metrics collection model

Stores time-series metrics efficiently

Integrated alerting with Alertmanager

Supports service discovery (Kubernetes, EC2, etc.)

2. Node Exporter

Installed on Linux machines (EC2 or local)

Exposes system-level metrics:

CPU usage

Memory usage

Disk I/O

Network stats

Filesystem usage

3. Grafana

Visualization and dashboard tool

Connects to Prometheus as data source

Prebuilt dashboards available in Grafana Hub

Custom charts, tables, and alerts
